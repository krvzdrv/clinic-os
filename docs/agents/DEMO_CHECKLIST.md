# Чеклист ручного демо (спринт 1)

Заполняет `clinic-qa` после сидов. Цель: гость по ссылке видит подсказку и проверку.

## Среда

- [ ] URL приложения (Render): `https://________________`
- [ ] Данные в Supabase (после сида), не localhost-only
- [ ] Каталог лекарств взрослый (КП №768)

## Пациенты

| Метка | ФИО / как найти на дашборде | Ожидание |
|---|---|---|
| A | _заполнит qa_ | Соответствует протоколу |
| B | _заполнит qa_ | Отклонение АБТ + рекомендация |
| C | _заполнит qa_ | Тяжёлая / госпитализация / нет АБТ |

## Сценарий для гостя (2–3 минуты)

1. [ ] Открыть URL (дождаться cold start Render при необходимости).
2. [ ] Открыть пациента **B**.
3. [ ] Вверху карточки виден блок протокола (не внизу среди форм).
4. [ ] Есть понятное отклонение **языком врача** (без ATC, без кодов gap).
5. [ ] Есть рекомендация «что сделать» (`next_step` / action).
6. [ ] Для контроля: пациент **A** — итог «соответствует» / без problem.
7. [ ] Для контроля: пациент **C** — видно показание к госпитализации или отсутствие АБТ.

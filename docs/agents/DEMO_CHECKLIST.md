# Чеклист ручного демо (спринт 1)

Заполняет `clinic-qa` после сидов. Цель: гость по ссылке видит подсказку и проверку.

## Среда

- [ ] URL приложения (Render): `https://clinic-os-xxxx.onrender.com` *(подставьте URL из панели Render)*
- [ ] Данные в Supabase (после сида), не localhost-only
- [ ] Каталог лекарств взрослый (КП №768)

## Пациенты

| Метка | ФИО / как найти на дашборде | Ожидание |
|---|---|---|
| A | **ДемоА** Антон Петрович | Соответствует протоколу (`compliant=True`, без problem) |
| B | **ДемоБ** Борис Иванович | Отклонение АБТ + рекомендация заменить на амоксициллин |
| C | **ДемоВ** Виктор Сергеевич | Тяжёлая амбулаторно: госпитализация + АБТ не назначена |

## Сценарий для гостя (2–3 минуты)

1. [ ] Открыть URL (дождаться cold start Render при необходимости, ~30–50 с).
2. [ ] На дашборде найти пациента **ДемоБ** (фамилия «ДемоБ»).
3. [ ] Вверху карточки виден блок протокола (не внизу среди форм).
4. [ ] Есть понятное отклонение **языком врача**, без ATC и без кодов gap — например:
   - «Назначен Азитромицин … по протоколу первая линия — Амоксициллин»
5. [ ] Есть рекомендация «что сделать» (`next_step` / action) **без ATC** — например:
   - «Нетяжёлая ВП без факторов риска → амоксициллин»
6. [ ] Для контроля: пациент **ДемоА** — итог «соответствует протоколу» / без problem.
7. [ ] Для контроля: пациент **ДемоВ** — видно показание к госпитализации и отсутствие АБТ.

## Команда сида

```bash
# из корня репозитория; DATABASE_URL — URI Supabase (pooler, порт 6543)
export DATABASE_URL='postgresql://...'

# полный набор (10 пациентов, включая ДемоА/Б/В):
PYTHONPATH=. python3 tools/seed_ten.py

# прогреть кэш (рекомендуется после сида):
PYTHONPATH=. python3 tools/warm_cache.py
```

**Пустая облачная БД** (первый деплой): при старте приложения `seed_demo()` создаст только трёх пациентов ДемоА/Б/В из `_seed_data.py`. Для полного набора — явно запустите `seed_ten.py`.

## Кого показать гостю

**Основной сценарий — пациент ДемоБ** (Борис Иванович): видно отклонение по АБТ и рекомендацию первой линии.

Краткий контраст:
- **ДемоА** — «всё по протоколу»
- **ДемоВ** — «тяжёлая, нужна госпитализация, АБТ нет»

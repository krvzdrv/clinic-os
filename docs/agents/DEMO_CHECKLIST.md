# Чеклист ручного демо (12 пациентов)

Цель: гость по ссылке видит **один** следующий шаг по протоколу и может пройти контрастные сценарии.
У каждого пациента **ровно 1 приём и 1 активный диагноз** (упрощение демо).

## Среда

- [ ] URL приложения (Render): `https://…onrender.com` *(из панели Render)*
- [ ] Данные в Supabase (после `seed_ten`), не только localhost
- [ ] Каталог лекарств взрослый (КП №768 / №23), ≥20 позиций в форме назначений

## Команда сида

```bash
# локально
CLINIC_DB=clinic.db python3 tools/seed_ten.py

# облако (Supabase) — из .env
python3 tools/seed_ten.py

# HTTP-аудит (сервер уже запущен)
python3 tools/audit_ten.py http://127.0.0.1:5591
python3 tools/live_ui_audit.py http://127.0.0.1:5591
```

`seed_ten` очищает клинические данные, создаёт 12 взрослых (ВП + ЖДА), каталог ЛС и кэш.
Кнопка на пустом дашборде даёт только Орлов/Б/В — для полного набора всегда `seed_ten`.

## Сценарий для гостя (2–3 минуты)

1. [ ] Открыть URL / дашборд — guest `page-banner` про Соколова («не та АБТ»).
2. [ ] **Открыть карту** → Соколов: CDS внутри диагноза + «Заменить на Амоксициллин».
3. [ ] Нажать «Заменить…» → вердикт зеленеет (азитромицин снят).
4. [ ] Контраст: **Орлов** (ок), **Морозов** (госпитализация), **Феррова** (ЖДА).
5. [ ] На дашборде колонки **«Вердикт»** и **«Сделать сейчас»** заполнены у всех.

## Override (осознанное назначение) — зеркало `doctor_gate` §5

1. [ ] Пациент с ВП и ожидаемой АБТ (напр. **Пустова** после заполнения / или чистый кейс).
2. [ ] Назначить **не** first-line АБТ без confirm → диалог / `need_confirm`, препарат **не** сохранён.
3. [ ] «Назначить осознанно» (`confirm=1`) → препарат активен, бейдж **«осознанно»**, вердикт **не** «соответствует».
4. [ ] Смена на препарат по протоколу → override снимается с картины, метрика может стать compliant.
